# Plan d’action SEO — Navpit

## Phase 1 — Critique (semaine 1)

1. **Déployer** le commit SEO (schema, llms.txt, robots, meta home).
2. **Search Console** : propriété `https://www.navpit.com`, vérification HTML (`GOOGLE_SITE_VERIFICATION` dans Vercel).
3. Soumettre `https://www.navpit.com/sitemap.xml`, demander indexation `/` et `/prix`.
4. Vérifier `https://www.navpit.com/llms.txt` et JSON-LD avec [Rich Results Test](https://search.google.com/test/rich-results).

## Phase 2 — Haute (semaines 2–3)

1. **Contenu** : 3 pages `/blog` ou `/guides` (800–1200 mots) — ex. « un seul projet en focus », « cockpit fondateur solo ».
2. **Internal linking** : footer + home vers ces guides.
3. **Open Graph** : vérifier image 1200×630 après déploiement.
4. Configurer **GA4** (`NEXT_PUBLIC_GA_MEASUREMENT_ID`) pour suivre l’organique.

## Phase 3 — Autorité (mois 2+)

1. Guest posts / newsletters indie FR, Product Hunt, comparatifs honnêtes.
2. Profils cohérents (LinkedIn, X) avec lien vers home.
3. Moz ou Bing Webmaster pour suivre referring domains.

## Phase 4 — Monitoring

1. Search Console : requêtes, CTR, pages non indexées.
2. CrUX trimestriel (LCP, INP, CLS).
3. Test citations IA : requêtes « outil focus projet fondateur solo français ».
